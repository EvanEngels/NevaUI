# 💡 Wake

|             |            |
| ----------- | ---------- |
| **Stage**   | 💡 Spark   |
| **Created** | 2026-09-09 |

## The idea

Fast movement leaves a trail of where it has been, which fades. The faster it goes, the
longer the wake.

## Why this one

Speed in an interface is usually invisible: something moved, and how fast is lost. A wake
puts it on screen — you can see that a flick was a flick.

## The line it must not cross

A wake behind slow movement is a smear, and a smear is decoration pretending to be
information. This has to be a function of **speed**, not of movement, or it is the second
thing rather than the first.

## Open questions

- What is fast enough to deserve a trail?
- Ghosts are copies. How much can wear one?
- Is there anything it tells the reader that they did not already know from having done
  the movement themselves?

## How this could fail

- It is pure decoration and the honest answer is to archive it.
- It smears at speeds people use all the time and makes the page feel greasy.
